## Come lavoriamo

Sprint di due settimane, con rotazione dei ruoli a ogni sprint. Ogni attività
è una issue, ogni modifica passa da una pull request verificata da un'altra
persona e le ore si registrano sulle issue. Le regole sono nelle
[Norme di Progetto](https://git-push-team.github.io/docs/) e, in breve, in
[CONTRIBUTING.md](https://github.com/Git-Push-Team/.github/blob/main/CONTRIBUTING.md).
